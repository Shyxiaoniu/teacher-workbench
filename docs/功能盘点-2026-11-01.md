# 班级工作台 2.0 · 功能盘点清单

> 盘点日期：2026-11-01
> 盘点范围：`app/` 全部源码（教师端 / 学生端 / 服务端 / 提交子系统）
> 用途：重构前的现状快照。后续每个功能是否保留、合并、删除，都以本表为基线。

---

## 0. 一句话现状

**能用的东西不少，但它们按"班主任工具箱"长出来，不是按"机房上课"的动线长的。**

- 服务端是一个 Python 单文件 HTTP 服务（`app/server.py`），跑在容器里、由 nginx 统一入口反代；
- 教师端是一个 **1.57 MB 的单页 HTML**（`app/index.html`，约 4.5 万行），18 个功能页全部塞在里面，靠 `location.hash` 切换；
- 学生端是独立小单页（`app/student/`），只有「今日 / 我的」两个页签；
- 数据层是 29 张表，浏览器端 `netsync.js` 每 1.5 秒扫差异、增量推给 `/api/v2/sync`，SSE 拉回来。

## 2. 当前运行形态

```
NAS（docker compose）
  gateway:8080  ──┬─ /      → workbench:20020  工作台主服务
                  └─ /qf/   → quickform:5055   QuickForm

workbench 容器内：
  ├─ /teacher/      教师控制台（登录后加载 index.html）
  ├─ /s/            学生端（student/index.html，局域网可访问）
  ├─ /submit/*      作业/测验提交页
  ├─ /g/*           小组/活动提交页
  ├─ /api/v2/*      鉴权 + 同步 + 事件(SSE)
  └─ /join          已删除，现 302 → /s/
```

- 同步链路：浏览器 `netsync.js` ⇄ `/api/v2/sync`（增量 push / pull）+ SSE 版本号；
- 数据与课件都在数据卷里（`WB_DATA_DIR=/app/data`），重建镜像不丢；
- 远端能力（NAS / 云）代码已具备，但没有接过真实远端。

## 5. 教师端全局壳（现状）

- 左侧栏：品牌位（问候语 + 好句）→ 5 组导航（常用/教学/班务/其他）；
- 顶栏：汉堡键 + **日期（可改为基准日期）** + **全局班级选择器** + 全局搜索 + 系统设置 + 设计者署名；
- 页面内：每页顶部有可折叠的「功能说明」，页脚有设计者信息；
- 弹窗：已统一为 `uiConfirm / uiPrompt / uiAlert`（工作台风格，无浏览器原生弹窗）。

**这三样是本次重构要动刀的地方**：顶栏的日期与班级选择器、设置入口的位置、18 页导航的分组逻辑。

## 8. 完成度统计

| 类别 | 数量 | 说明 |
|---|---|---|
| 功能页（教师端） | 18 | 16 个可用、1 个依赖外部服务、1 个待并入座位表 |
| 学生端模块 | 3 | 登录 / 今日 / 我的 |
| 数据表 | 29 | 全部有读写链路 |
| 服务端接口 | 40+ | 鉴权 9、同步 3、教师 15、学生 6、管理 3 |
| 已知遗留问题 | 5 | ①框选几何（已修 3 轮）②活动外部服务依赖 ③单页文件过大（1.57 MB）④导航 18 项无动线逻辑 ⑤顶栏承载了全局状态（日期/班级） |

**结论：功能不缺，缺的是"这节课怎么上"这条主线。** 18 个页面对班主任是齐全的，对一位站在机房里的信息科技老师来说，开机后第一步该干什么、学生该看到什么，界面上没有答案。

## 9. 已确认要做的调整（延续 11-01 需求）

| 项 | 决定 | 原因 |
|---|---|---|
| 考勤页 | 删除独立页，统计并入座位表（统计卡 + 可点筛选 + 病假/事假标记） | 老师是在座位表上点人的，不需要另一个页面 |
| 导学单页 | 删除独立页，作为"资料类型"并入课件页的下发资料 | 一节课只该有一个"发东西"的入口 |
| 课件页 | 只保留「课件库」+「下发资料」，去掉「资料夹（挂本地目录）」 | 三个页签概念重叠，老师分不清 |
| 学生端 | 界面现代化，底部按钮加边框 | 学生机屏幕小、手指粗，现有 2 个页签无容器感 |
| 顶栏 | 去掉全局班级选择器与日期；日期移到问候语下方 | 顶栏该放"我在哪、现在做什么"，不放"全局面板" |
| 设置 | 从左下角常驻入口进入，含账号信息 + 系统设置 | 设置是低频但必须随手可达的 |
| 三端 | 服务端（NAS 容器）/ 教师端 / 学生端 职责重新划清 | 学生端与教师端共用同一个入口，全部由 NAS 提供服务 |

- 凡是标 ✅ 的项，均在 2026-10-31 ~ 11-01 的实测中走通过主流程；标 🟡 的项有明确已知缺口，已写在备注列。
