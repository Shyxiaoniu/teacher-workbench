# 课堂活动：自研模块说明

> 版本：班级工作台 2.0 · 2026-11-03
> 对应代码：`app/activity.py`（数据层）、`app/server.py`（接口）、`app/index.html`（活动管理面板）

## 一、为什么自研

课堂活动需要的能力只有两件事：**存活动与提交、给个管理界面**。
身份（学号/姓名/班级）、鉴权（签名票）、活动发放、数据大屏、课件归档、
备份，本来就都是工作台自己做的。

自研的关键收益在数据模型：提交表里直接有 `sid / name / cls` 列，
「按班统计提交率」「缺交名单」可以直接查库，不用在前端拼 JSON。
同时少一个外部组件、少一套账号、少一层地址适配。

> 历史：2026-11-03 之前这里曾集成第三方表单服务 QuickForm；自该日起
> 课堂活动由本项目自研实现，QuickForm 源码已从本仓库整体移除。

## 二、数据落在哪

| 内容 | 位置 |
|---|---|
| 活动（act_task） | `<数据目录>/workbench.db` |
| 提交（act_submission） | 同上，`data` 列存原始 JSON，`sid/name/cls/ip` 单独成列 |
| 附件记录（act_file） | 同上 |
| 附件文件 | `<数据目录>/activity/<活动号>/<12位随机名>.<ext>` |
| 对外 URL | `/static/uploads/<活动号>/<文件名>` |

> 备份口径已合一：全量备份（`full=1`）里包含 `activity` 段
> （tasks / submissions / 附件 base64），换机恢复一次到位。

## 三、接口

公开接口（已开启 CORS，学生自建提交页可直连）：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/act/tasks` | `{success:true, tasks:[{task_id,title,api,count}]}` |
| GET | `/api/act/<task>` · `/all` | 全部提交（含 `_submission_id`、`submitted_at`） |
| GET | `/api/act/<task>/count` | `{total_submissions}` |
| POST | `/api/act/<task>` | 匿名提交（老师自建页面直连用） |
| GET | `/static/uploads/<task>/<file>` | 附件（图片/PDF/音视频内联，其余强制下载） |

教师端专用（须登录）：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v2/teacher/activity/list` | 活动列表 + 提交数 + 资料附件 |
| GET | `/api/v2/teacher/activity/data?task=` | 单活动全部提交 |
| GET | `/api/v2/teacher/activity/export?task=&format=csv|json` | 导出（CSV 带 BOM） |
| POST | `/api/v2/teacher/activity/save` | 新建 / 修改（带 task_id 即修改） |
| POST | `/api/v2/teacher/activity/delete` | 删活动（连带提交、附件、发放记录） |
| POST | `/api/v2/teacher/activity/clear` | 清空提交 |
| POST | `/api/v2/teacher/activity/del-sub` | 删单条提交 |
| POST | `/api/v2/teacher/activity/upload?task=` | 上传教学资料（multipart，单文件 40MB） |

数据大屏的读/清空/删单条走 `/api/v2/act-data`、`/api/v2/act-clear`、
`/api/v2/act-del-sub`（教师会话鉴权）。

学生提交仍走 `POST /api/v2/student/submit?t=<票>`：身份由服务端从票里取，
页面自己填的学号会被覆盖（防冒名）。

## 四、已知边界

- **不做多用户/角色**：教师身份就是工作台的教师会话，学生身份就是票。
- **不做 AI 分析、图表报告、二维码、模板导入导出**：实际课堂没这个需求；
  需要时在工作台里另做（数据已经能直接查）。
- **附件上限**：单文件 40MB、整份提交 40MB；备份打包时
  单文件 >10MB 或合计 >40MB 会跳过并点名，不静默丢。
- **历史数据兼容**：`activity.file_path()` 仍识别带 `/qf/static/uploads/`
  前缀的旧附件地址（旧备份里可能存有），对外不再提供 `/qf/*` 路由。
