# 班级工作台 2.0 · 双端版使用说明

一台教师机 = 服务端 + 教师端。学生用浏览器（手机/电脑）访问教师机，免安装。

## 启动

| 平台 | 双击 |
|---|---|
| Windows | `启动教师端.bat` |
| macOS | `启动教师端.command` |
| Linux | `启动教师端.sh` |

默认端口是 **20020**（不常用端口，避开 8080/3000/5000 这些常被其他软件占用的号）。
老安装首次启动时会自动迁移到 20020，只迁移一次。

启动后终端会打印：

- 教师端（本机）：`http://127.0.0.1:20020/teacher/`
- 学生端（局域网）：`http://<教师机IP>:20020/s/`
- 学生端控制台：`http://127.0.0.1:20020/teacher/console`
- 投屏二维码：`http://127.0.0.1:20020/join`

关闭启动窗口即停止服务。

### 端口被占用时

启动器会**自动弹出「端口设置」窗口**：有图形界面时是原生小窗（tkinter），
没有 tkinter 时会用本机浏览器打开一个「端口设置」页（只在 127.0.0.1 上临时存在）。
填一个新端口点「保存并继续启动」即可，端口会写进 `data/config.json`，下次直接沿用。
命令行加 `--no-dialog` 可以关掉弹窗（开机自启等无人值守场景）。

| 操作 | 命令 |
|---|---|
| 指定端口 | `python launch.py --port 20200` |
| 查谁占用端口 | Windows `netstat -ano \| findstr :20020`；macOS/Linux `lsof -i :20020` |

## 账号与密码

| 端 | 怎么登录 |
|---|---|
| 教师端 | 账号 + 密码（首次打开 `/teacher/` 时创建，默认账号 `teacher`，同时**必须设置密保问题**）。忘记密码 → 登录页点「忘记密码」，回答密保问题即可自助改密；也可在教师端「设置 → 账号与密码」里改（密保验证，不需要旧密码）。两个都忘了：在本机运行 `python launch.py --reset-password` |
| 学生端 | 定位为**课堂使用**：登录后**一键签到**（教师端座位表实时看到）、查看老师下发的**学习资料**、查看并**提交作业**。**不开放请假入口**——病假 / 事假由教师在教师端登记（考勤页每行「病假 / 事假 / 补签」按钮，或座位表点学生）。整节课未签到的学生，本节结束后**自动记为旷课**（也可点「结算本节」立即结算） |
| 学生端 | 选班级 → 选学号（姓名自动带出）→ 输密码。名单直接读取教师端「学生」页，改名册立即生效 |

学生密码策略在「学生端控制台」设置：

- **全班统一初始密码**（默认 `123456`）：改了以后新登录用新密码；
- **每人独立密码**：没单独设过密码的学生无法登录；
- **首次登录必须改密码**：学生用初始密码进来后先设新密码；
- **全部重置为初始密码**：一键清掉所有学生改过的密码。

学生密码哈希只存在教师机的 `data/workbench.db`，不参与同步、不出现在任何接口响应里。

## 考勤标签与筛选（座位表 / 考勤页通用）

- **状态色块**：座位卡右下角的考勤标签是彩色色块——已签到=绿、未签到/迟到/早退=橙、
  病假=蓝、事假=灰、旷课=红（深浅色主题都校过对比度）；本节还没人有记录时不显示，避免满屏「未」。
- **点统计标签筛选**：座位表 / 考勤页上方的「课堂签到」统计条里，每个标签都能点——
  - 座位表：命中的卡片**描边 + 轻微放大**，其余卡片淡化；再点同一个标签（或点「全部」/「✕ 取消筛选」）恢复；
  - 考勤页：统计条下方展开**对应学生名单**（姓名、学号、班级/座位、状态、记录时间、备注），
    点表头可按字段排序（再点反向），右上角可**导出当前筛选结果**（CSV / Excel，只导列表里的这些人）；
  - 筛选后统计条下面会显示「命中 N 人」的反馈条，0 人时明确提示「本节没有这类学生」。
- 名单口径与统计条完全一致：同一天、同一节、按节次记录，不改任何数据来源。

## 数据

- 全部业务数据存 `data/workbench.db`（SQLite，WAL）；
- 每天首次启动自动快照到 `data/backup/`，保留 14 份；
- 学习资料下发：教师端「课件 → 📤 下发资料」，按班级下发（链接 / 文件 / 文字），学生端「资料」页签只读查看；
- 备份导出：`http://127.0.0.1:20020/api/v2/teacher/export`（教师登录后访问）；
- 迁移 = 复制整个 `data/` 目录到新电脑。

## 数据备份与迁移（浏览器侧）

- 入口有两处，**同一个面板、同一套实现**（`app/backup.js` 的 `BackupIO`）：
  顶栏 ⚙ 系统设置 → 数据与备份；工具页「💾 数据备份与迁移」卡片。
  在哪边导出 / 恢复效果完全一致，文件格式相同、互相可还原。
- 设了锁屏密码 → 导出 `.cwbackup` 加密文件（跨设备还原用导出时的密码）；
  没设密码 → 导出 `.json` 明文。文件带条目数与校验和，损坏会中止导入。
- 导入只替换数据、不替换本机密码；密码凭据（`wb-lock-hash` 等）不进备份。
- 页面右上角「🐮 牛老师设计」与右下角「已连接服务端」胶囊为常驻标识，
  均不遮挡内容；迷你计时条 / 学生面板出现时胶囊会自动上移避让。

## 同步机制（一句话版）

教师端任何改动 → 服务端记一条变更（全局版本号 rev）→ 学生端收到信号拉增量。
学生端只拿得到“本班 + 本人”的字段投影；手机号、家长信息、他人成绩在服务端就裁掉了。
关闭某模块（如成绩）时，学生端入口消失、接口直接 403。

## 局域网部署要点

1. Windows 防火墙放行 20020（专用网络）；没有管理员权限时让网管放行；
2. 教师机接电源、设置「从不睡眠」；
3. 建议 DHCP 保留 / 静态 IP，学生链接才稳定；
4. 校园 Wi-Fi 若开 AP 隔离，学生连不上教师机 → 用教师机热点或小交换机；
5. 机房还原卡机器：把 `data/` 放到非还原盘；
6. 无需外网、无需管理员权限（除防火墙放行）。

## 常用命令

```bash
python launch.py --port 20200           # 指定端口
python launch.py --no-browser           # 不自动开浏览器（配合开机自启）
python launch.py --no-dialog            # 端口被占时不弹窗（开机自启用）
python launch.py --reset-password       # 清除教师密码与密保，下次重新设置
python server.py --port 20200           # 直接起服务（调试用）

# 生成 / 清理演示数据（服务运行中执行）
python tools/seed_demo.py                              # 3 个班 × 40 人
python tools/seed_demo.py --classes 5 --students 45    # 自定义规模
python tools/seed_demo.py --prefix "演示-"             # 班级名加前缀
python tools/seed_demo.py --clean                      # 删掉演示数据
```
