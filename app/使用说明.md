# 班级工作台 2.0 · 双端版使用说明

工作台以 Docker 方式部署在 NAS（或一台常开的服务器）上，教师端、学生端与 QuickForm
共用**同一个网页入口**，学生用手机浏览器访问，免安装。

## 启动与入口

```bash
docker compose up -d          # 启动（init → 工作台 / QuickForm → 网关）
docker compose ps             # 看状态，都 healthy 即可用
docker compose stop           # 停止（数据卷保留）
```

把 `<NAS>` 换成 NAS 的局域网 IP 或域名（默认端口 8080，由 `.env` 的 `WEB_PORT` 决定）：

| 入口 | 地址 |
|---|---|
| 教师端 | `http://<NAS>:8080/teacher/` |
| 学生端 | `http://<NAS>:8080/s/` |
| QuickForm | `http://<NAS>:8080/qf/` |
| 学生端控制台 | `http://<NAS>:8080/teacher/console` |
| 投屏二维码 | `http://<NAS>:8080/join` |

换端口只改 `.env` 里的 `WEB_PORT`，然后 `docker compose up -d`——二维码与学生端地址
按「老师当前打开的地址」自动生成，不需要改任何链接。

> `app/启动教师端.bat|.command|.sh` 与 `launch.py` 是**开发调试**用的本地启动方式，
> 正式使用请走 Docker：只有容器里的服务才是长期在线的那个。


## 账号与密码

| 端 | 怎么登录 |
|---|---|
| 教师端 | 账号 + 密码（首次打开 `/teacher/` 时创建，默认账号 `teacher`，同时**必须设置密保问题**）。忘记密码 → 登录页点「忘记密码」，回答密保问题即可自助改密；也可在教师端「设置 → 账号与密码」里改（密保验证，不需要旧密码）。两个都忘了：在服务器上执行 `docker compose exec workbench python launch.py --reset-password` |
| 学生端 | 定位为**课堂使用**：登录后**一键签到**（教师端座位表实时看到）、查看老师下发的**学习资料**、查看并**提交作业**。**不开放请假入口**——病假 / 事假由教师在教师端登记（考勤页每行「病假 / 事假 / 补签」按钮，或座位表点学生）。整节课未签到的学生，本节结束后**自动记为旷课**（也可点「结算本节」立即结算） |
| 学生端 | 选班级 → 选学号（姓名自动带出）→ 输密码。名单直接读取教师端「学生」页，改名册立即生效 |

学生密码策略在「学生端控制台」设置：

- **全班统一初始密码**（默认 `123456`）：改了以后新登录用新密码；
- **每人独立密码**：没单独设过密码的学生无法登录；
- **首次登录必须改密码**：学生用初始密码进来后先设新密码；
- **全部重置为初始密码**：一键清掉所有学生改过的密码。

学生密码哈希只存在服务端数据卷（`/app/data/workbench.db`）里，不参与同步、不出现在任何接口响应里。

## 数据

- 全部业务数据存数据卷里的 `workbench.db`（SQLite，WAL）；
- 课件库默认在同一个数据卷的 `courseware/`（容器内 `/app/data/courseware`），
  重建镜像、升级版本都不会丢；
- 每天首次启动自动快照到 `data/backup/`，保留 14 份；
- 学习资料下发：教师端「课件 → 📤 下发」推送到指定班级的指定课节，学生端在导学单的
  「课件库」区块按课节查看；
- 迁移 = 一键导出全量备份 + 课程资料包（见下节），不要手工拷数据库文件。

## 考勤标签与筛选（座位表 / 考勤页通用）

- **状态色块**：座位卡右下角的考勤标签是彩色色块——已签到=绿、未签到/迟到/早退=橙、
  病假=蓝、事假=灰、旷课=红（深浅色主题都校过对比度）；本节还没人有记录时不显示，避免满屏「未」。
- **点统计标签筛选**：座位表 / 考勤页上方的「课堂签到」统计条里，每个标签都能点——
  - 座位表：命中的卡片**描边 + 轻微放大**，其余卡片淡化；再点同一个标签（或点「全部」/「✕ 取消筛选」）恢复；
  - 考勤页：统计条下方展开**对应学生名单**（姓名、学号、班级/座位、状态、记录时间、备注），
    点表头可按字段排序（再点反向），右上角可**导出当前筛选结果**（CSV / Excel，只导列表里的这些人）；
  - 筛选后统计条下面会显示「命中 N 人」的反馈条，0 人时明确提示「本节没有这类学生」。
- 名单口径与统计条完全一致：同一天、同一节、按节次记录，不改任何数据来源。

## 数据备份与迁移

- 入口：顶栏 ⚙ 系统设置 → 数据与备份（`app/backup.js` 的 `BackupIO`）。
- **一键导出全量备份**：点一次、设一个备份密码（同一个弹窗里输两遍），得到一个 `.cwbackup`
  加密文件，内含整库 29 张表 + 全部配置 + 教师账号 + 学生口令哈希 + 打字练习成绩（金币、装扮）
  + 学生作品附件 + 浏览器里的界面设置。
- **一键恢复**：新设备上选文件、输入同一个备份密码即可，服务端与本机一起还原，刷新即用。
- **出错会明确说明**：文件不完整 / 密码不对 / 备份来自更新版本 / 备份数据量明显少于本机 /
  服务端未启动 / 登录失效，都会弹窗告知原因，且失败时不改动任何数据。
- **附件体积上限**：单个 ≤ 10 MB、合计 ≤ 40 MB；超出的附件不进备份文件，导出时会点名提示。
- **课程资料包**：课件库里的文件本身单独打成一个 `.zip`（保留课程子目录）。
  换机 / 重建容器后：先一键恢复，再导入课程资料包，课件库的记录与文件才对得上。
- 导入只替换数据、不替换解锁密码；密码凭据（`wb-lock-hash` 等）不进备份。
- 页面右上角「🐮 牛老师设计」与右下角「已连接服务端」胶囊为常驻标识，
  均不遮挡内容；迷你计时条 / 学生面板出现时胶囊会自动上移避让。

## 同步机制（一句话版）

教师端任何改动 → 服务端记一条变更（全局版本号 rev）→ 学生端收到信号拉增量。
学生端只拿得到“本班 + 本人”的字段投影；手机号、家长信息、他人成绩在服务端就裁掉了。
关闭某模块（如成绩）时，学生端入口消失、接口直接 403。

## 机房 / 局域网部署要点

1. NAS 用**固定 IP**（或 DHCP 保留），学生链接才稳定；
2. 只放行一个端口：`WEB_PORT`（默认 8080）。工作台 20020、QuickForm 5055 都只在容器网络内，不需要对外；
3. 机房 Wi-Fi 若开 AP 隔离，学生手机连不上 NAS → 关掉隔离，或让学生连同一个交换机的 Wi-Fi；
4. NAS 关机 / 休眠 = 全班掉线：把电源策略设为不休眠，并让 Docker 随系统自启；
5. 数据都在两个数据卷里，机房还原卡不影响（还原的是学生机，不是 NAS）。

## 常用命令

```bash
docker compose up -d                    # 启动全部服务
docker compose ps                       # 状态（healthy 即可用）
docker compose logs -f workbench        # 工作台日志
docker compose logs -f quickform        # QuickForm 日志
docker compose restart workbench        # 只重启工作台
docker compose exec workbench python launch.py --reset-password   # 清除教师密码与密保
docker compose down                     # 停止并删除容器（数据卷保留）
```

桌面调试（仅开发用）：`python launch.py --port 20200` / `--no-browser` / `--no-dialog`。
