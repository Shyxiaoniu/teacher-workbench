这一页怎么用

一节课的完整流程，四步。

  1. 开启开关：右上角的大开关一点就生效，学生端不用刷新页面。
  2. 填归档课程：建议就叫「网页设计」。学生交的作品会落到 资料 / 网页设计 / 七年级(3)班 / 20260312-张三 / 下面。
  3. 学生做作品：左边写 HTML/CSS，右边实时预览；中途可以「保存草稿」， 换台电脑登录还能接着写。
  4. 看作品：选「上课」页 → 上方课程选「网页设计」→ 学生作品墙里就是截图。 也可以在下面的「最近提交」里直接点开看大图。

给学生的两个提醒

· 预览只运行 HTML/CSS，不执行 JavaScript —— 这样一句写错的脚本不会把课堂电脑卡住。

· 外链图片在截图里可能显示成灰块，作业建议用 emoji、 渐变 或纯 CSS 画的图形，交上来一定看得见。
